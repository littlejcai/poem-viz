# 「诗画同源」界面重设计 · 三方共用设计 spec

## 产品是什么
「诗画同源」——小学必背古诗词学习小工具。130 首课内必背诗，每首配一幅程序化生成的水墨画（Canvas 绘制，非图片）。双端分发：小红书小程序（离线 zip 包）+ Web 静态站（learning.caistudio.cn/poem-viz）。

核心功能（真实存在，demo 内容从这里取材，禁止 Lorem ipsum）：
- 诗集列表：按年级（一到六年级）筛选、搜索诗名/作者/诗句
- 诗详情：水墨诗意图、拼音/平仄标注、背诵打卡（亲子对背）、诗画卡/字帖/日签/合照卡生成
- 练习中心 7 个游戏：诗句接龙、意象猜诗、补画、诗序拼图、对仗连连看、平仄对对子、飞花令
- 诗径地图：130 首排成登山小径，背一首点亮一处
- 诗人页：65 位诗人的小传与作品
- 每周战报：本周背诗首数、连续打卡天数、称号（童生/秀才/举人…）

真实内容样例（直接用）：《咏鹅》骆宾王「鹅，鹅，鹅，曲项向天歌」、《静夜思》李白「床前明月光，疑是地上霜」、《江南》汉乐府「江南可采莲，莲叶何田田」、《山行》杜牧「霜叶红于二月花」。

## 目标受众与使用场景
6–12 岁孩子 + 陪学家长。手机竖屏为主（375–414px 宽）。典型场景：睡前/路上家长带娃背一首诗，孩子自己玩练习游戏挣称号。界面要让孩子愿意点、让家长觉得"这钱花得值/这东西做得用心"。

## 情感基调
温润、书卷气、东方美学；但不能老成——要有童趣和惊喜感（孩子是第一用户）。避免：老气横秋的红木风、冷冰冰的极简 SaaS 风、花哨低幼的幼儿园贴纸风。

## 现有设计语言（重设计的起点，可延续可颠覆）
米色宣纸底（#f5efe4 一带）、KaiTi 楷体诗文、朱砂红印章点缀、水墨灰蓝山水 Canvas。现状问题是"实用工具感"重、设计完成度不够。三个方向自由发挥，但都要回答"form 来自内容的哪里"。

## 视觉母题线索（内容的独有物，供 form 推导）
印章/钤印、宣纸纹理与墨色晕染、卷轴与册页、诗行竖排、平仄的节奏感（长短/起伏）、飞花令的"花"、诗径的"登山路"。

## 输出格式与尺寸（三版必须统一）
单文件 HTML，在 **1440×900** 画布上并排展示该方向下的 **3 个手机界面**（每个 375×812 竖屏，带细腻的设备边框或留白卡片均可）：
1. 诗集列表首页（含顶栏、搜索、年级筛选、诗卡片）
2. 一首诗详情（《山行》或《咏鹅》，含画区、诗文、工具条、背诵按钮）
3. 练习中心 或 诗径地图（二选一，选能体现该方向设计力的）

## 硬约束（最终落地环境，demo 设计必须能"翻译"回去）
- 无框架纯 HTML/CSS/JS，离线环境：禁止外部字体 CDN、禁止外部图片 URL——字体只用系统字体栈（KaiTi/STKaiti/serif/-apple-system 等），装饰图形只用 CSS/SVG/Canvas
- Chrome 61 / ES2017 基线：不用 CSS 新特性（如 :has、容器查询、color-mix）做关键路径
- 整包 ≤2MB
- demo 中涉及"诗意图"的位置：用 CSS 渐变/抽象山水示意即可，不必复刻 Canvas 水墨

## 可读性硬底线（任何风格不豁免）
正文 ≥14px、标签注释 ≥12px、正文对比度 ≥4.5:1；留白必须是构图不是内容缺席。

## 反 AI slop 提醒
禁紫渐变、禁 emoji 当图标、禁"圆角卡片+左色条"的烂大街组合；印章/朱砂要用得像设计师做的，不像模板贴的。
